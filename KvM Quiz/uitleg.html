Start live quiz

Elke les wordt afgesloten met een korte interactieve quiz over de stof van die les. Leerlingen doen live mee vanaf hun eigen apparaat.

Hoe werkt het
Leerling
Scant een code of opent een link, en beantwoordt de vragen live mee vanaf zijn eigen apparaat.
Docent
Op het grote scherm zie je per vraag direct de antwoorden en het klassement binnenkomen.
Stappenplan
1
Open de quiz
Start de sessie vanuit het docentenportaal.
2
Leerlingen doen mee
Ze scannen de code of openen de link op hun eigen apparaat.
3
Volg het live
Antwoorden en klassement verschijnen per vraag op het grote scherm.
4
Sluit af
Bespreek kort de winnaar en eventuele lastige vragen.
